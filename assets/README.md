# Assets

Place repository visual assets here:

- `banner.png` — README banner (referenced, currently commented out, at
  the top of `README.md`)
- `confusion_matrix.png` — output of `scripts/evaluate.py`
- `training_history.png` — output of `plot_training_history()`
- `sample_images.png` — output of `plot_sample_images()`

Once you've run training/evaluation and generated these, uncomment the
corresponding `<!-- ![...](assets/...) -->` lines in `README.md`.
